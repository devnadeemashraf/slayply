Honest answers to job application questions

Slayply is a Chrome side panel. Give it a job description and the questions, and it drafts answers using only facts you saved about yourself, with every claim traceable to its source.

Download the extension (zip)

Free and unofficial. It has had one real test (answer generation with a Gemini key) and little else, so expect rough edges. Read the disclaimer first.

What it does

  • Keeps your profile, resumes and saved jobs in your browser only.
  • Drafts answers, cover letters and messages with the model you choose (Claude, OpenAI or Gemini).
  • Flags any first-person sentence that does not cite one of your saved facts.
  • Never fills in or submits an application form for you.

Install

From the download

  1. Download the zip above and unzip it. You should see a folder containing manifest.json.
  2. Open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked and select the unzipped folder.
  4. Open the Slayply side panel, add your own API key in Setup, and start from the privacy screen.

It is not on the Chrome Web Store, so Chrome does not update it. To update, download the new zip and replace the folder. Each release lists a SHA-256 checksum so you can verify the file.

Or build it yourself

  1. Download or clone the repository and run pnpm install.
  2. Run pnpm --filter @slayply/extension build.
  3. Open chrome://extensions, turn on Developer mode and choose Load unpacked.
  4. Select apps/extension/.output/chrome-mv3, then open the Slayply side panel.
  5. Add your own API key in Setup. You pay your provider directly; Slayply has no accounts or fees.

Self-host the relay

The relay forwards requests to your provider and keeps no prompts, answers or keys. The repository's render.yaml deploys it to Render. The extension has a fixed ID, iljnmipngombklkmmjlfgbgdbnagbnbn; set EXTENSION_IDS to it, and rebuild the extension with WXT_RELAY_URL pointing at your relay.
